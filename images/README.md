# Bilder-Ordner

Lege deine Bilder hier rein und pushe sie ins Repository.

## Welche Dateinamen werden erwartet:

| Dateiname       | Verwendung                              |
|-----------------|-----------------------------------------|
| `hero.jpg`      | Großes Produktfoto im Hero-Bereich      |
| `clipper.jpg`   | Bild nur vom Clipper (optional)         |
| `trimmer.jpg`   | Bild nur vom Trimmer (optional)         |

## Unterstützte Formate
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## Hinweis
Das Bild `hero.jpg` wird automatisch als Vollbild-Hintergrund im Hero der Website angezeigt.
